# Brown Sheep Creatives

Brown Sheep Creatives is a two-person indie game studio built around a simple bet: AI systems belong in the engine, not bolted on after the fact.

## What We're Building

### Marrow's End — Psychological Horror FPS

Our flagship title. Marrow's End is a psychological horror FPS set in a dying logging town of the same name, built around a proprietary **Dread system** that adapts to how you play rather than following a fixed script.

Key pillars:

- **Adaptive horror** — the Dread system reads player behavior and adjusts pacing, tension, and threats in response, so no two playthroughs feel identical
- **Three distinct enemy archetypes** — The Gleaner, Kindred, and The Undergrowth, each built around a different predatory logic
- **Hub-and-spoke level design** — a central town hub branches into self-contained, atmosphere-driven excursions
- **Full game design document** completed, with accompanying portfolio materials (interactive web version and PDF)

A mobile prototype exploring the game's mood and mechanics — *Night Watch* — has also been built.

### AI-Native Game Engine

Underpinning our games is a proprietary engine designed from the ground up around AI as a first-class system, not an afterthought. It integrates:

- Behavior trees and GOAP (Goal-Oriented Action Planning) for NPC decision-making
- LLM-driven dialogue and NPCs with persistent memory
- ML inference as a native engine subsystem
- Core systems: ECS, rendering pipeline, physics, audio, and asset management

This engine is our core technical moat — the foundation for our own titles today, with potential for licensing down the line.

## Studio Structure

Brown Sheep Creatives operates as an LLP (Limited Liability Partnership), with a 50:50 profit split and joint sign-off on major decisions between partners. Internally, we're organized into three departments: Creative Development, Business Operations, and Production/QA.
