## 🎮 What We're Building

### 🩸 Marrow's End — *Psychological Horror FPS*

Our flagship title. **Marrow's End** drops you into a dying logging town of the same name, powered by a proprietary **Dread System** that adapts to how you play — no fixed script, no two playthroughs alike.

<table>
<tr>
<td width="50%" valign="top">

**🧠 Adaptive Horror**
The Dread system reads player behavior and reshapes pacing, tension, and threats in real time.

**👹 Three Enemy Archetypes**
The Gleaner, Kindred, and The Undergrowth — each driven by a distinct predatory logic.

</td>
<td width="50%" valign="top">

**🗺️ Hub-and-Spoke Design**
A central town hub branches into self-contained, atmosphere-driven excursions.

**📄 Full GDD Complete**
Portfolio-ready design document, with interactive web + PDF versions.

### ⚙️ AI-Native Game Engine

Our secret weapon: a proprietary engine built from the ground up around AI as a **first-class system**, not an afterthought.

| System | Description |
|---|---|
| 🌲 **Behavior Trees + GOAP** | Goal-Oriented Action Planning for smarter NPC decision-making |
| 💬 **LLM-Driven Dialogue** | NPCs with persistent memory and dynamic conversation |
| 🧮 **Native ML Inference** | Machine learning as a core engine subsystem, not a plugin |
| 🏗️ **Core Engine Systems** | ECS · Rendering Pipeline · Physics · Audio · Asset Management |

This engine is our **technical moat** — powering our own titles today, with room to license down the line.
